# aniketdivecha.github.io

Personal website for Aniket Divecha, deployed on GitHub Pages.

## Structure

- `index.html` - single-page site content
- `styles.css` - styling
- `assets/aniket.jpg` - portrait photo
- `assets/og-card.jpg` - social share card image
- `favicon.svg` - site icon

## Updating

Edit `index.html` directly, commit to `main`, and GitHub Pages redeploys automatically within a minute or two.

## Local preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.
